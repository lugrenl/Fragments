# Android Fragments Playground

Этот проект представляет собой песочницу для изучения различных аспектов работы с фрагментами в Android. Проект разделен на 10 частей, каждая из которых демонстрирует конкретную концепцию.

## Части

1.  **Simple Fragment**: Демонстрация базового использования фрагментов.
2.  **Fragment Factory**: Использование `FragmentFactory` для создания экземпляров фрагментов.
3.  **Fragment Managers**: Работа с `FragmentManager` и `childFragmentManager`.
4.  **Lifecycle**: Жизненный цикл фрагментов и его отличия от жизненного цикла Activity.
5.  **Transactions**: Выполнение транзакций с фрагментами: добавление, замена, удаление.
6.  **Backstack**: Работа с бэкстеком для управления навигацией между фрагментами.
7.  **Turn**: Вращение устройства и сохранение состояния фрагмента.
8.  **Communications**: Взаимодействие между фрагментами, а также между фрагментом и Activity.
9.  **No UI Fragment**: Использование фрагментов без пользовательского интерфейса для выполнения фоновых задач.
10. **Dialog Fragment**: Создание и использование диалоговых фрагментов, включая `BottomSheetDialogFragment`.
